# 🖼 Mini Photoshop - Pengolahan Citra Digital

Aplikasi pengolahan citra digital berbasis web sebagai proyek akhir mata kuliah **Pengolahan Citra Digital**.

## 🛠 Tech Stack
- **Backend:** Python + FastAPI + OpenCV
- **Frontend:** React + Tailwind CSS
- **ML:** TensorFlow (CNN Object Recognition)

## ✨ Fitur
- Image Enhancement (Brightness, Contrast, Histogram Equalization)
- Geometric Transformation (Rotate, Flip, Crop, Resize)
- Image Restoration (Gaussian Blur, Median Filter, Noise Removal)
- Binary & Edge Processing (Canny, Sobel, Prewitt, dll.)
- Color Processing (RGB, Grayscale, Channel Splitting)
- Image Segmentation
- Image Compression
- Histogram Analysis
- Object Recognition (CNN)

## 🚀 Cara Menjalankan

### Backend
```bash
cd backend
uvicorn main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm run dev
```
